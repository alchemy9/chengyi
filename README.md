# 承艺 3.0 · 初版

可探索、可参与创作的中国非遗数字世界。本版只开放**陶瓷**；其他器物只能预览，界面标为「即将开放」。流程到分享为止，个人场馆以后再做。

本目录是完整项目：网页在根目录，后台（承艺 AI、语音、作品同步，原「非遗陶艺工作台」）在 `server/`，由同一个服务托管。

视觉以《承艺-代码实现交接包》的四张定图和《陶瓷篇章》九张图为准：墨青底色、低饱和青绿、少量暖金。1.0 版里的画风和元素都没有沿用。

## 怎么打开

- **Mac：双击 `start.command`。** 它先启动后台，再自动打开 `http://127.0.0.1:8000`（端口被占用时顺延到 8001…）。关闭时在启动窗口按 Ctrl+C。
  - `server/runtime/` 里带了 Apple 芯片的便携 Python，不用另装。第一次打开如果提示“无法验证开发者”，在文件上点右键选“打开”，或到“系统设置 → 隐私与安全性”点“仍要打开”。
  - 没有自带运行环境时，会找本机的 Python 3.12 以上版本，第一次启动需要联网安装依赖（装在 `server/.venv`）。
  - 一个都找不到时，退回纯网页预览（`tools/serve.py`，端口 5180）：所有画面和手动操作照常，承艺 AI 改用本机关键词理解，没有语音。
- **Windows：双击 `启动承艺-Windows.bat`**，需要 Python 3.12 以上。
- 手动启动后台：在 `server/` 里执行 `python scripts/launch_shared.py`（会自动初始化数据库，`--no-browser` 不开浏览器，`--port` 换端口）。
- 只看网页：在本目录执行 `python3 tools/serve.py`。
  - **不要用** `python3 -m http.server`：它不支持 HTTP Range 请求，浏览器就没法跳转视频进度，篇章里随滚动播放的视频会卡在第一帧。
- 不能直接双击 `index.html`：浏览器不允许本地文件加载 JS 模块，也不允许读取图片像素（粒子要用到）。
- 需要支持 WebGL 的新版 Chrome、Edge 或 Safari。按桌面 1440×900 和 1280×800 设计；手机竖屏下工作台改为上方五步、下方面板。

## 完整流程

| 场景 | 看到什么 | 怎么操作 |
| --- | --- | --- |
| 序章 | 暗青星尘背景。光点在呼吸，金尘缓慢漂浮。「万千手艺，由此生光」逐字显现 | 叙事结束后出现「寻光入境」，点它或向下滚动入场。右上角可以开关声音、切换动态效果、跳过 |
| 光核过场 | 即梦生成的过场视频：光核扩散，穿行，落到山河 | 只播放一次，可以跳过。视频最后约一秒，地图叠在视频上交叉淡化，两者取景按特征点逐像素对齐，不会跳。声音在结尾 1.4 秒内淡出。之后五件器物由近及远依次浮现，界面最后出现 |
| 山河地图 | 地形、雾、器物都在同一坐标系里。金色光点沿河道由远向近流动，移动鼠标有短拖尾 | 拖动平移，滚轮或 ＋/－ 缩放（以鼠标为中心，有边界）。悬停器物显示名称和开放状态。拖动不会误触器物。左下角可以重播序章 |
| 器物近景 | 中央只有一件实体器物，左右两件是金色粒子轮廓 | 点击后，地图镜头先向器物推进，再由器物从当时的屏幕位置飞到中央。点左右两侧切换：旧实体散成粒子退到侧边，新器物由粒子聚合成实体。也可以用 ← →。Esc 或左上角返回地图，返回时恢复原来的视角 |
| 陶瓷篇章 | 八幕连续滚动：择土、练泥、成形、施釉、入窑、成器、归土、承艺。同一件器物在幕与幕之间连续变化：素坯缩到远处“上釉”成为青花瓶；远景瓶在同一个镜头里推近到瓶身特写；窑中的瓶从原位升起成为成品；成品从右向左碎裂，落成土堆 | 滚轮、触控板或方向键推进，向上滚动可以回看。鼠标移动有轻微视差。右侧小点可以跳到某一幕，顶部「跳过，直接创作」直接进工作台 |
| 工作台 | 接续篇章最后一幕「承艺」：同一张展台底图，三维坯体按透视立在画中的青铜圆台上，左侧「择土 · 练泥 · 成形 · 施釉 · 入窑」与篇章结尾的流程线同位，光柱里有浮尘 | 五步：**择土**选泥料（赤陶、白瓷、紫砂、黑陶）；**练泥**定坯形（玉壶春、花器、陶罐、茶碗、直筒杯）与高度、最大径；**成形**在坯体上按住左右拖动拉坯（手掌、刮刀、细针、抚平四种手法），俯视形状可选爱心、花瓣、方、六边、星等，可只改口沿或上半部，打开俯视小窗查看，也可用摄像头手势；**施釉**选釉色（素烧或九种）、光泽、开片、纹样与纹色。拖动空白处转动转盘，滚轮推近拉远。撤销、重做；草稿自动保存在本机 |
| 承艺 AI | 底部对话条，例如「做个爱心碗」「瓶口收一点」「施天青釉配缠枝莲」 | 直接修改作品，可撤销；改了哪一步，面板就切到哪一步。可以按住话筒说话，回复可朗读。「给我灵感」换一组搭配 |
| 入窑 · 分享 | 升温、窑火、还原、开窑 | 在「入窑」一步取名、落款后点火。生成 1080×1350 的分享图（画中展台 + 你的器）。可以保存图片、复制文案，支持时还能调用系统分享。之后可以再做一件，或回到山河。也可另存图片、OBJ 三维模型和工程文件，或打开工程文件继续做 |

**直达地址**（评审和截图用，会跳过序章）：`#map`、`#object`、`#object?id=papercut`、`#chapter`、`#chapter?p=0.45`（停在篇章 45% 处）、`#workbench`。后台页面：`/admin`（模型与声音设置）、`/demo`、`/voice`、`/docs`（接口文档）。

## 声音

只播放真实的音频素材，不再用代码合成音色（上一版合成的低频长音会忽大忽小，听起来很怪，已经去掉）。

- **过场视频自带的声轨**：结尾淡出，不会被截断。
- **环境声**：目前没有素材，所以除了过场，其余场景都是安静的。有了素材后，把文件放进 `assets/audio/`，在 `assets/audio/index.json` 里写 `{ "ambient": "文件名.mp3" }`，就会循环播放（低音量，渐入渐出，过场时自动压低）。

## 用视频模型提升画面

陶瓷篇章里有几处变化，靠平面图片做不出真实效果：泥团揉压、素坯转面、瓶体碎裂、泥土堆积。网页已经留好接口，视频文件放进去就能随滚动逐帧播放，向上滚动时倒放。

`docs/视频模型分镜.md` 里有八段分镜：首尾帧用哪两张图、时长、镜头运动、提示词，以及生成后怎么转码（`tools/encode_scrub.sh`）。缺哪段就用代码动画补哪段，可以一段一段替换。

## 承艺 AI 与后台

- **联网时**：网页把作品整份同步给后台，每次手动修改都是后台历史里的一步。你说的话先由后台规则处理（「施天青釉」「做个茶碗」「高度改成 20 厘米」这类明确说法，不调用模型）；其余交给 Dify 上的「非遗讲解人」Agent，它按 15 个工作台工具返回操作，后台校验、算出新的作品，网页修改真实的三维模型后回执，收到回执才显示“已改好”并朗读。参数不合规或 Agent 没给出可执行的操作时，不修改作品。
- **Agent 暂时不可用**（未配置 Key、超时、额度用完）时，能用本机规则理解的话照常执行，并注明来源。
- **只用网页预览时**：承艺 AI 用本机关键词规则，规则与后台的工具实现一致（`js/pottery/model.js` 的 `applyLocal`）。
- **按住说话、朗读回复**需要后台开启硅基流动语音，并允许麦克风。单次录音不超过 30 秒。
- Key 只在 `server/.env`，网页拿不到。后台托管网页时只公开 `index.html`、`css`、`js`、`assets`、`tests`，`server/`、`tools/`、`docs/` 一律 404。
- 管理员账号在 `server/后台账号.txt`。在 `/admin` 填写或更换 Dify 应用 Key、硅基流动 Key、音色。
- 网页与后台分开部署时，在 `index.html` 里设置 `window.CHENGYI_API_BASE = 'https://后台地址'`，并把网页的地址加进 `server/.env` 的 `CORS_ORIGINS`。
- 工具清单与接法见 `server/docs/陶艺工作台接入.md`，提示词、语音、数据库、部署见 `server/docs/` 下其他文档。

## 模拟边界：哪些是真的，哪些还没做

- **塑形是真的**：坯体是 96 层轮廓 × 128 段的旋转体，拉坯、俯视形状、局部单侧调整都会改变网格本身，导出的 OBJ 就是这个网格（单位厘米）。网页与后台用同一套几何规则（`js/pottery/geometry.js` ↔ `server/app/pottery_geometry.py`）。器物仍是单个有底、开口的器形，不能加把手、开侧孔。
- **釉色、纹样、开片是预览**：画在展开的柱面贴图上，缠枝莲、云纹、海水为程序绘制，纹样会按器身比例调整，不会被拉扁。施釉后圈足留一圈露胎。
- **作品保存在本机浏览器**，联网时同步到后台会话（24 小时）；没有账号和公开分享链接，个人场馆以后再做。
- **其他器物只能预览**：人偶、团花纹饰、花丝饰件、编篮的名称都是按外观起的，**没有核实过**，界面上标了「示意」。这四件只有地图上的小图（最小的编篮只有 73 像素高），近景里放大不超过约 2 倍，所以显示得比青瓷小。
- **陶瓷篇章是 2.5D 分层**：没有分层源文件，所以从整图里拆出图层（见下）。泥团揉压、素坯转面是用分层变形和光影模拟的，不是真实转面。真实效果要靠视频模型（见上）。
- **泥料、釉色的简介**是概括性的描述，未经内容组逐条核实。

## 素材来源与处理

- `assets/img/`：序章、地图、近景的背景，以及近景分层和五件器物，取自《承艺-代码实现交接包-樊烨》，转成 JPEG 或压缩过的 PNG。
- 工作台底图就是篇章最后一幕的 `assets/story/s9.jpg`（9.png 去字）。三维相机按图中圆台顶面的椭圆（中心 834, 658，半轴 362 × 39，设计稿 1672×941 像素）反算俯角与距离，坯体立在画中台面上。
- `assets/story/`：陶瓷篇章 1–9 图，处理方法：
  - **去字**：检测笔画（连同文字的辉光一起），再用 LaMa 修补。图 5 的三条引线、图 9 的流程线也一并去掉，改用网页文字和线条重画。
  - **抠图**：主体用 BiRefNet 抠图模型抠出，边缘柔和、无锯齿。图 9 → 9，1 的土堆直接用两张图相减得到，最准确。
  - **主体移走后的底图**：用 LaMa 修补，连同主体的辉光一起去掉，不会留下淡影。图 7 的瓶移走后，改用图 8 去掉瓶和碎片后的纯背景。
  - **成品瓶**：取自 `ChatGPT 图像 2026年10月18日 16_31_03.png`。
- 「玉壶春」坯形：从 `青瓷云纹瓶-无背景-自然釉面.glb` 提取外轮廓（96 层，高 30 厘米），写在 `js/pottery/model.js` 和 `server/app/pottery.py`；网页不再加载 GLB。
- `assets/video/enter.mp4`：即梦生成的入场视频，重新编码过（16MB 压到 3.4MB）。

重新生成素材：`python3 tools/prep_assets.py <承艺3.0 文件夹路径>`。需要 pillow、numpy、scipy、opencv-python-headless、rembg[cpu]、torch、simple-lama-inpainting。首次运行会下载 BiRefNet（约 1GB）和 LaMa（约 200MB）模型。

## 测试

- **网页端到端**：启动后打开 `/tests/flow.html`。它会自动走一遍：序章 → 过场 → 地图缩放 → 近景切换（包括连续点击）→ 返回地图 → 篇章滚动和回看 → 工作台五步手动操作、撤销重做 → 承艺 AI → 灵感 → 入窑 → 分享。用后台启动时测联网的 Agent 路径（36 项），用 `tools/serve.py` 预览时测本机规则（37 项）。顶部 `RESULT n/n` 表示全部通过。
- **后台**：在 `server/` 里执行 `python -m pytest -q`（需要先装 `requirements.txt`）。覆盖施釉工具、玉壶春坯形、旧作品兼容、本机指令不调用模型、整站托管时不泄露后台文件。
