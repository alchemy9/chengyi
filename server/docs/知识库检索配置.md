# 非遗知识库检索排查与配置

## 已核对的情况

2026 年 10 月 15 日，使用已配置的 Dify 应用 API，在新会话中发送用户原句“讲讲青花缠枝莲纹碗”。请求成功，调用了“非遗知识库”的检索工具，没有调用博查。

返回来源包含《收藏品介绍.docx》的 C001 青花缠枝莲纹碗条目；该条目包含明永乐、故宫博物院藏、尺寸、碗心折枝石榴及外壁缠枝莲等资料。以上说明该条目在这次运行中可以检索，不代表所有会话的工具选择已经稳定。

在 Dify 知识库页面确认三个文档均为“可用”并已启用。当前知识库描述为：

> useful for when you want to answer queries about the 手工制作教程.docx

它只描述了教程，没有覆盖收藏品和陶瓷工艺。旧版 Agent 会参考知识库描述决定是否检索，因此这是一项需要修正的配置，但尚不能仅凭一次成功测试认定此前失败只由这一项引起。当前索引与阈值无需为了这次问题盲目修改。

## 建议替换的知识库描述

在“知识库 → 非遗知识库 → 设置 → 描述”中替换为以下正文并保存：

本知识库用于非遗展馆的藏品讲解、陶瓷工艺问答和手工制作引导，包含《收藏品介绍.docx》《陶瓷工艺介绍.docx》《手工制作教程.docx》。具体藏品的名称、特点、年代、尺寸、纹饰、用途和文化意义，应检索收藏品资料；陶瓷材料与制作工序，应检索工艺资料；材料工具及分步操作，应检索教程。例如“讲讲青花缠枝莲纹碗”“碗心是什么纹样”属于本知识库查询范围。仅使用文档实际记载的信息，不预设每件藏品都包含上述全部字段。

## 验证顺序

1. 保存完整的知识库描述。
2. 在 Agent 编辑页暂时关闭博查，使这一阶段只使用本项目资料；保存并发布需要用于 API 的应用版本。
3. 新建或清空测试会话，再发送“讲讲青花缠枝莲纹碗”。查看运行记录或来源，确认知识检索发生且命中《收藏品介绍.docx》的 C001。
4. 如果应用未调用知识库，在知识库的“召回测试”中输入“青花缠枝莲纹碗”，分别核对工具选择与资料命中。召回测试中的临时检索参数不会自动成为知识库的正式配置。
5. 后续确有联网需求时再启用博查。提示词要求本项目资料问题先检索知识库，但提示词无法严格保证所有工具选择；需要强制执行时，可用 Chatflow 的知识检索节点先取资料，再由模型生成讲解。

更新后的系统提示词保存在《Agent系统提示词.md》，已增加具体藏品先检索以及博查仅在明确联网请求时使用的规则。本次未修改或发布云端配置，本文与提示词需应用到 Dify 后再验收。
