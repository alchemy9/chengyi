# 模型接入与部署

## 本机状态

已接入 Dify Cloud 的“非遗讲解人”旧版 Agent。Dify 负责知识库检索、讲解问答及工作区默认语音识别；硅基流动 CosyVoice2 负责分句播报。密钥已保存在后端 `.env`，不在前端或本文中展示。

## 配置

```dotenv
LLM_MODE=live
LLM_PROVIDER=dify
LLM_API_BASE_URL=https://api.dify.ai/v1
LLM_MODEL=非遗讲解人
LLM_API_KEY=你的Dify应用密钥
SPEECH_ENABLED=true
SPEECH_API_KEY=你的硅基流动密钥
SPEECH_VOICE=anna
```

这些密钥值是占位说明。Dify 的 model 字段只是本地显示名称；实际模型、知识库、默认识别模型均由 Dify 应用和工作区设置控制。此适配支持 Chatbot 和旧版 Agent，未验证新版 Agent 或 Workflow。

管理页面保存模型、声音配置立即生效，响应只返回是否已配置，不回传 Key。直接编辑 `.env` 后需要重启服务。更换模型平台或 provider 需要提供新的 Key。

Dify 保存 Prompt 后，需要发布供 API 使用的版本；后台不会通过应用 Key 改写云端 Prompt、知识库描述或索引。系统提示词见 `Agent系统提示词.md`，检索排查见 `知识库检索配置.md`。

语音识别使用 Dify `/audio-to-text` 与稳定访客标识；调用工作区默认识别模型，不能使用聊天模型代替。浏览器录音编码为真实 WAV，由后台验证并上传。

播报直接调用硅基流动 `/audio/speech`，不再次调用 Dify 的朗读功能，也不依赖 Agent 主动选择音频工具。音色为 CosyVoice2 的 Anna、Bella、Alex、Benjamin、Charles、David。选择由本地后台维护，不依赖 Dify 界面 Alloy 列表。

也保留通用 Chat Completions 接入，provider 设为 chat_completions，填写对应基础地址和模型名称。Dify 地址末尾不加 `/chat-messages`，直接模型地址末尾不加 `/chat/completions`。

## 时间与状态

LLM_TIMEOUT_SECONDS 限制一次模型或识别请求的时间；Dify 的输出长度由应用设置及 Prompt 控制，LLM_MAX_TOKENS 只发送给直接 Chat Completions 供应商。SPEECH_TIMEOUT_SECONDS 限制每句合成时间，语音整轮最长 180 秒、最多播报 4000 字。

没有自动重试，避免一次操作产生重复调用。LLM_FALLBACK_ENABLED 控制模型故障后是否展示本地资料；连接测试始终直接报告失败。

后端维护本地会话，每轮显式传入当前物品、部位、资料与最近十条有效本物品历史，Dify 远程会话每次重新创建。模型与音频错误只返回错误类别和可理解提示，供应商异常正文与密钥不会传给访客。

声音体验页已启用 PCM 边生成边播放，首段提前按短语切分，同轮复用语音连接；原 MP3 接口保留兼容。它去掉收齐整句音频的等待，但无法消除 Agent 检索、工具选择与模型生成第一句的耗时。实际速度见验收记录，不保证固定响应时间。

## 运行与正式部署

本机运行 `启动后台.command`，只监听 127.0.0.1:8000。也可运行 `.venv/bin/python scripts/run_local_background.py` 独立启动，不依赖聊天临时终端；日志与进程编号在 data 目录。正式前端跨电脑联调需要共同可访问的地址。

正式部署设置 ENVIRONMENT=production、SEED_DEMO_DATA=false，精确配置 CORS_ORIGINS，在服务器环境变量配置模型、语音和数据库。页面不能修改正式环境密钥，公开调试文档关闭。

迁移数据库后启动服务，配置 HTTPS；代理对 SSE 关闭缓冲，并给语音请求足够超时。Docker 与远程数据库尚未上线实测。多进程或多实例前需要共享限流，当前内存限流只适合单进程。

本地 C001 已注册关联知识库，其他三件内容仍是演示资料。新部署需迁移或重新录入真实资料，关闭自动示例插入不会删除已有数据。

官方接口参考：[Dify 聊天 API](https://docs.dify.ai/en/api-reference/guides/chat)、[Dify 语音识别](https://docs.dify.ai/en/api-reference/audio/convert-audio-to-text)、[硅基流动声音合成](https://docs.siliconflow.cn/docs/api/audio-speech-post)。
