# 陶艺工作台接入

本机入口：<http://127.0.0.1:8000/#workbench>（旧地址 `/workbench/` 会自动跳转）。管理后台顶部也有入口。

> 2026-10-19 起，工作台已并入承艺网页：页面在项目根目录（`js/workbench.js`、`js/agent.js`、`js/pottery/`），后台在 `server/`，由同一个服务托管。原来 `app/static/workbench/` 下的独立页面已删除。画面接续陶瓷篇章最后一幕，左侧为「择土 · 练泥 · 成形 · 施釉 · 入窑」五步。Dify、语音服务的 Key 仍只保存在后端。

## 已接入的操作

| 工具 | 当前实现 |
| --- | --- |
| get_workbench_state | 读取实际器形、高度、最大直径、口部直径、釉色、光泽、转盘和视角 |
| set_base_shape | 切换玉壶春（取自青瓷云纹瓶模型的外轮廓）、花器、陶罐、茶碗、直筒杯，重置对应轮廓与高度 |
| set_dimensions | 调整高度或整体最大直径，单位厘米 |
| reshape_region | 调整指定高度区域的半径，区域两端平滑过渡 |
| set_shape_profile | 从控制点生成完整轮廓，使用单调三次曲线插值，避免圆肚出现折角 |
| smooth_surface | 抚平指定高度区域 |
| set_cross_section | 设置整体或指定部位的俯视轮廓，可使用爱心、三角形、方形、长方形、多边形、椭圆、星形、花瓣、水滴和自定义极坐标控制点 |
| set_material | 择土：赤陶泥、白瓷泥、紫砂泥、黑陶泥，以及 0–100% 光泽。旧作品里的青瓷釉、天青釉会转成白瓷泥施对应釉色 |
| set_glaze | 施釉：素烧或九种釉色（影青、天青、粉青、豆青、月白、甜白、霁蓝、霁红、乌金），纹样（素面、云纹、缠枝莲、海水），纹色（青花、釉里红、描金、墨彩），开片，光泽 |
| set_wheel | 启停和每分钟转数 |
| set_view | 正面、透视（工作台主镜头固定对准展台，二者相同）、俯视（打开俯视小窗）、缩放 |
| undo / redo | 撤销、恢复，保留最近40次修改；手动修改会同步到后台历史 |
| save_project | 保存当前工程和作品名称到后台数据库 |
| export_artifact | 从实际画布/网格生成 PNG、OBJ 或 JSON，页面显示下载链接 |

模型采用原工作台的96层半径轮廓、128段旋转几何。高度范围8–40厘米，半径范围1.92–17.4厘米；设置最大直径后还会检查每一层半径是否超限。局部高度比例0表示底部，1表示顶部。不能把直径参数当成半径使用。

可输入：`施天青釉`、`加缠枝莲纹`、`做个玉壶春`、`先做一个茶碗`、`把高度改成25厘米`、`把瓶口收窄一些`、`暂停转盘`、`从上面看看瓶口`、`撤销`、`保存这个作品`、`导出一个三维模型`。

组合需求示例：`做成细颈、圆肚的花瓶，高度25厘米，换成青瓷釉，光泽低一点`。

## Dify 与执行过程

上述明确句式使用本地解析，其他表达交给已配置的 Dify Agent。后台发送工作台状态、最近已确认的操作、15个工具的参数约束以及用户请求。Dify 返回 JSON，后台校验并计算目标状态，页面修改实际模型后提交回执。收到成功回执后才展示和朗读完成反馈。非法参数或模型输出不符合协议时不修改作品。

本次已在云端原有系统提示词前加入工作台模式，保留藏品讲解与非遗知识库规则，并发布更新。原提示词备份为 `Dify接工作台前的提示词.txt`，更新后的完整提示词为 `Dify工作台与讲解提示词.txt`。

当前本机接法不要求在 Dify 工具列表再添加工作台工具。Dify 根据后台提供的协议返回操作参数，后台负责调度执行。独立工具的 OpenAPI 描述在 `/api/v1/workbenches/tools/openapi.json`，包含15个工具名称；云端直接调用工具尚未配置。Dify Cloud 无法访问用户电脑上的127.0.0.1。以后如改为云端直接调工具，还需部署可访问的服务并处理每个工作台的身份与权限，不能共用一个访客凭证。

## 接口

除创建和工具描述外，下表接口均需 `X-Session-Token`。创建响应包含 `session_token`、`session.id` 和 `project`。访客凭证默认24小时过期；工程存储在数据库，当前页面使用浏览器会话恢复凭证，没有账号作品库。

| 方法 | 路径（统一加 /api/v1） | 用途 |
| --- | --- | --- |
| POST | /workbenches | 使用 document 创建工程及访客会话 |
| GET | /workbenches/{id} | 读取已确认状态、revision、历史数量及 pending 操作 |
| POST | /workbenches/{id}/sync | 同步完成的手动修改 |
| POST | /workbenches/{id}/commands | 解析文字指令 |
| POST | /workbenches/{id}/tools/{tool_name} | 直接调用单个工具 |
| POST | /workbenches/{id}/commands/{command_id}/receipt | 报告实际执行结果 |
| POST | /workbenches/{id}/cancel | 作废待执行及仍在解析的旧指令 |
| POST | /workbenches/{id}/speech | 朗读已确认操作或 Agent 回答，使用 PCM SSE |
| POST | /sessions/{session_id}/transcribe | 转写按住说话生成的 WAV |

指令请求包含 `expected_revision`、UUID格式的 `client_request_id` 和 `text`。同一请求编号重发会返回同一操作，不能更换内容。工具请求将 `text` 换为 `arguments`。回执包含 `expected_revision`、`status`、实际 `document`，导出还需返回格式、文件名、字节数。文件二进制保留在浏览器，不上传大体积OBJ到数据库。页面关闭后，工具操作不会假装已完成；未执行指令90秒后过期。

工作台返回409时，应重新读取状态。手动编辑和点击停止会作废旧解析结果。回执重试不能重复修改模型或重新导出文件。不要把模型返回的字符串当作 JavaScript 执行。

## 语音与验证

按住按钮录音、松开发送，WAV为16kHz、16位、单声道，最多30秒。识别结果进入与文字相同的指令处理流程。首次使用麦克风需用户允许权限，录音前停止助手自己的声音。回复使用硅基流动24kHz PCM流式播放，修改模型不等待声音合成。

2026-10-18，真实 Dify 组合指令解析约4.27秒；浏览器画面出现细颈圆肚器形，高度25厘米、青瓷釉、光泽20%。已在浏览器验证器形切换、高度、转盘启停、俯视、手动釉色同步、读取状态、撤销恢复、局部收窄、抚平、保存、PNG/OBJ/JSON生成；JSON已实际下载并核对96层轮廓、25厘米、釉色与转盘字段。

一段2.68秒的合成测试语音正确转写为“把高度改成25厘米”，转写耗时约8.88秒；这验证了语音服务链路，不代表实际麦克风或口音准确率。当前是按住说话后识别，尚未达到持续实时语音响应。摄像头手势仍使用原工作台功能，本次没有开启摄像头测试。

75项Python检查及4项原有客户端控制器检查通过；覆盖工作台鉴权、执行回执、撤销恢复、取消迟到结果、过期处理、重复请求和非法组合操作。数据库迁移前已在 data/ 保存备份，Alembic结构检查通过。

## 非圆形与精细塑形更新

三维模型已从圆形旋转曲面改为96层、每层128个方向的轮廓网格，底面、内壁、口沿和外壁一同生成；OBJ导出使用同一实际网格。新的参数保存在 document.cross_section、section_bands 和 deformations，旧工程读取时补圆形默认值。JSON工程使用版本2，保留造型、转盘姿态和视角；版本1工程仍能导入，新造型需要在当前工作台打开。

set_cross_section可使用整体形状或部位形状，后添加的局部形状在高度区域内平滑过渡；例如圆身配爱心口沿、爱心身配三角形口沿。提供shape时会暂停转盘并切到俯视，其他视角可随后设置。roundness控制边角圆润程度，aspect_ratio控制宽深比例，lobes控制星角或花瓣数量。custom支持3–32个按角度递增的正半径控制点，用于近似不规则闭合轮廓。

reshape_region和smooth_surface可使用part指定whole、mouth、neck、shoulder、belly、base、upper、middle、lower，也可提供开始和结束高度比例。reshape_region提供radius_delta_cm或radius_scale_percent中的一项。side=front/back/left/right表示当前观察方向的一侧；后台结合转盘姿态换算为器物坐标角度，单侧操作会暂停转盘。angle_deg用于继续修改同一物理位置，与非all的side互斥。angular_width_deg限定该侧受影响的角度范围。

用户未给数值时，Agent按“稍微”“明显”等描述选择幅度，无需让用户输入参数。“再收窄一点”“再鼓一点”等简短续句会沿用最近实际执行的部位和固定方向，转动观察视角后也不会改到另一侧。一次复合指令中的修改只占一个撤销步骤。

示例：做个爱心碗；改成三角形；只把瓶口变成爱心，瓶身保持圆；瓶肩鼓一点；左边的肚子压进去一点；边角再圆一点。

这些形状指从上面看的轮廓。当前模型仍是单个有底的开口器物，不支持把手、侧面通孔、悬空分支或任意人物雕塑。

几何检查覆盖前后端数值一致、内外表面闭合、三角面方向及有符号体积；测试了全部内置形状、自定义轮廓、局部形状组合与单侧变形，导出网格通过检查。
